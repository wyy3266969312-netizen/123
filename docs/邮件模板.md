# 邮件模板

Supabase 发出去的验证邮件长什么样，由 [Authentication → Emails →
Templates](https://supabase.com/dashboard/project/epeavzkmaoiauxkkehta/auth/emails)
决定。默认模板是英文的，买家收到会愣一下，所以这里存一份中英对照的。

改完记得点保存，模板是立刻生效的，不用重新部署。

## 为什么是表格布局

QQ 邮箱、163、Outlook 会把 `flex`、`grid`、`<style>` 标签和外部样式表全部
砍掉。邮件 HTML 只能用 `<table>` 排版 + 全内联样式，写法看着很旧，但那是唯一
在所有客户端里都成立的写法。同理：不放图片（很多客户端默认不加载）、不用
web font、宽度固定 600px。

## 改完怎么验

在付费墙点「忘记密码？」，填一个**注册过的**邮箱，发一封给自己。

注意：`recover` 接口对**没注册过**的邮箱一律返回成功但不发信（防止被拿去探测
谁有账号）。所以拿没注册的邮箱测，无论配置对错都收不到信 —— 排查的时候先
去 Authentication → Users 确认地址在不在里面，能省很多时间。
